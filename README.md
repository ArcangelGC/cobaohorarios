# 🏫 COBAO - Sistema de Gestión de Horarios

[![PHP](https://img.shields.io/badge/PHP-7.4+-777BB4.svg)](https://php.net)
[![MySQL](https://img.shields.io/badge/MySQL-5.7+-4479A1.svg)](https://mysql.com)

Sistema de gestión de horarios para el **Colegio de Bachilleres del Estado de Oaxaca (COBAO)** - Plantel 38 Tlaxiaco.

---

##  Descripción

Aplicación web para administrar horarios escolares, permitiendo gestionar grupos, materias, maestros, salones y asignaciones de manera fácil e intuitiva.

##  Características

- 👥 **Grupos** - Gestión por semestre
- 📚 **Materias** - Catálogo por tipo (Tronco, Especialidad, Núcleo)
- 👨‍🏫 **Maestros** - Registro y disponibilidad
- 🏛️ **Salones** - Administración de espacios
- 📅 **Horarios** - Asignación con días y horas
- 🔗 **Asignaciones** - Relación materia-grupo-maestro
- 📊 **Dashboard** - Estadísticas en tiempo real
- 🎨 **Diseño COBAO** - Colores institucionales

## 🛠️ Tecnologías

- PHP 7.4+
- MySQL 5.7+
- Bootstrap 5
- Font Awesome 6
- JavaScript (ES6)

## ⚙️ Instalación

1. Clonar el repositorio en `C:/xampp/htdocs/`
2. Crear base de datos `cobaohorarios` en phpMyAdmin
3. Configurar `config/database.php` con tus credenciales
4. Acceder desde: `http://localhost/cobaohorarios/`
